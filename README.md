# FanDuel Player Data - As of 10/26/2026

## What this is
A free spreadsheet of **every player game** we track across **NBA, NHL, NFL, MLB, WNBA, PGA and NASCAR** - 262,892 player-games so
far - with the **FanDuel fantasy points** each player scored in each game, plus season summaries (points per game, last 5 and last 2
games, best and worst game, and every stat FanDuel scores).

It comes from the history a daily-fantasy lineup project keeps for its own research. We share it so anyone can look up how a player has
actually been scoring in FanDuel terms - who is hot, who is cold, who is consistent - without building the data themselves.

## Kept up to date
The data is **updated after every slate we build lineups for and every set of results we process**, so the sport that just played gets
its newest games within a day. The date in every file name and title ("As of ...") is when it was last refreshed. Older versions stay
in this repository's commit history.

## How to use it
* **Everything in one file:** [`ALL_SPORTS_player_data_as_of_2026-10-26.xlsx`](ALL_SPORTS_player_data_as_of_2026-10-26.xlsx) - open the **Cover**
  tab first: it lists every tab, explains every column, shows the FanDuel scoring table for each sport, and says how to filter.
* **One sport only:** open its folder below. Each has its own workbook (same Cover page) and CSV files, which GitHub shows as a searchable
  table right in the browser.
* **Summary tabs** = one row per player per season. **Game Log tabs** = one row per player per game, newest first; filter "Games Ago"
  to 1-5 to see everyone's last five games.
* **No Excel?** The .xlsx files open free in Google Sheets (upload to Google Drive, then open with Google Sheets), Excel for the web,
  LibreOffice Calc and Apple Numbers. The CSVs open in anything.

## Where the data comes from
Stat lines come from the leagues' public box scores (NBA and MLB stats sites, the NHL game center, ESPN for NFL, WNBA and PGA, NASCAR's
results feed - each sport's folder names its source). **FanDuel points are calculated** from those stats with FanDuel's published
scoring rules; they are not supplied by FanDuel and can differ slightly when a league corrects a stat after the game. Preseason games
are left out; playoff games are included.

**Not included:** FanDuel salaries, projections, ownership percentages or contest results, anything read from FanDuel's own pages, and
anyone's entries.
